# Getting help

| You want to… | Go to |
|---|---|
| Learn how to use the app or write a plugin | [Docs](https://pkuharness.com/en/docs) (中文: [/docs](https://pkuharness.com/docs)) |
| Ask a question, share an idea, show what you built | [GitHub Discussions](https://github.com/pkuinfo/pku-harness/discussions) |
| Report a bug in the app (chat, dashboard, schedule, Copilot, settings) | [App issues](https://github.com/pkuinfo/pku-harness/issues/new/choose) |
| Report a broken campus service, or ask for a new one | [Plugin issues](https://github.com/pkuinfo/pku-harness-plugins/issues/new/choose) |
| Report a website or marketplace problem | [Website issues](https://github.com/pkuinfo/pkuharness-website/issues/new/choose) |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md) |

Before you post:

- Search existing issues and discussions; your question may already be answered.
- Include the app version (Settings → About), Android version and device model.
- **Never post passwords, cookies, tokens, student IDs or other personal data**, and redact
  screenshots.

PKU harness is maintained by student volunteers, so answers can take a few days. The university's
own IT services can't help with this app; it is not an official Peking University product.

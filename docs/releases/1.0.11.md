## 更新内容

- 语音输入：点聊天框里的麦克风说话，文字边说边出现，说完即可修改后发送；使用你自己的阿里云百炼或硅基流动 API Key
- 修复三星等手机在使用 Copilot 后键盘需要点两次的问题：任务结束后自动关闭 Copilot 的无障碍服务，下次任务时再打开
- Copilot 遇到付款时把页面交给你，用指纹或密码付完点「完成 · 继续」，它会自己接着做完
- Copilot 更稳：不再同时操作多个控件，置灰的选项会先打开它依赖的开关
- 长任务中上下文超出预算时自动压缩，不再等任务结束
- 你用什么语言提问，就用什么语言回答
- 工具调用记录在回答开始后自动折叠
- 全新导航栏和悬浮底部标签栏；隐私政策更新提示改为原生底部面板
- 「关于」页面加入永久开源、免费的承诺和贡献者

## What's new

- Voice input: tap the mic in the chat box and speak; the words appear as you talk, ready to edit and send. Uses your own Alibaba Cloud Bailian or SiliconFlow API key
- Fixed the keyboard needing two taps per key on Samsung and other phones after using Copilot: its accessibility service now turns off when a task ends and back on for the next one
- Copilot hands payment pages to you: pay with your fingerprint or password, tap "Done · continue", and it finishes the task by itself
- Copilot is steadier: one control at a time, and it turns on the switch a greyed-out option depends on
- Long tasks compact their context as soon as it passes the budget, without waiting for the task to end
- Replies come in the language you write in
- Tool calls fold away once the answer starts
- New top bars and a floating tab bar; the privacy update notice is now a native bottom sheet
- About now shows our promise to stay open source and free, and the contributors

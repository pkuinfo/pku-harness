## 更新内容

- Copilot 的悬浮球在 PKU harness 里也一直显示了（以前一回到 PKU harness 就收起，看不到任务还在进行）；悬浮窗换回不会被任何页面遮住的显示方式，「显示在其他应用上层」这一步不再需要
- 微信小程序交给你时如果重新加载回到了首页，Copilot 会先在你的屏幕上把它点回结算页（悬浮窗会提示稍等），再交给你
- Copilot 会记住做成一件事的最短步骤（「Copilot 路线」，在「设置 → AI 记忆」里可以查看、修改和删除），下次做同样的事直接照着走，不再从头摸索
- Copilot 在页面很大的应用（如微信、小程序）里点按更快：等待页面变化时不再反复读整页
- 排队中的消息新增「立即发送」：点一下就停下当前回复、先处理这条消息，正在进行的 Copilot 任务不会被关掉

## What's new

- Copilot's floating ball now stays visible inside PKU harness too (before, it disappeared there, so there was no sign the task was still running). The floating window is back to the kind no screen can hide, and the "Display over other apps" step is gone
- When a WeChat mini program reloads to its home page on its way to your screen, Copilot first taps it back to the checkout page on your screen (the floating window asks you to wait), then hands it to you
- Copilot remembers the shortest steps that got a task done ("Copilot routes", which you can view, edit or delete in Settings → AI memory) and follows them the next time instead of finding its way again
- Faster Copilot taps in apps with big pages such as WeChat and mini programs: waiting for a page to change no longer re-reads the whole page
- Queued messages have a Steer button: it stops the current reply and sends that message next, and a running Copilot task stays open

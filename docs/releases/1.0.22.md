## 更新内容

- 直接提问就好：助手会自己找到合适的插件并加载，包括插件市场里你还没装的社区插件（安装仍需你确认）
- 界面更简洁：去掉对话页的示例问题、欢迎流程中的插件选择、附件菜单里的“输入命令”（输入 / 仍可打开命令菜单）；新装应用的看板只保留“今天”一张卡片
- 欢迎流程仍会引导开启助手（Copilot）权限，可以跳过
- 应用名统一写作 PKU harness

## What's new

- Just ask: the assistant finds and loads the plugin it needs by itself, including community plugins from the marketplace you haven't installed yet (installing still asks you first)
- A quieter app: no sample questions in a new chat, no plugin picker in the welcome flow, no Command row in the attach menu (typing / still opens the command menu); a new install's dashboard starts with just the Today card
- The welcome flow still walks you through Copilot permissions, and you can skip it
- The name is written PKU harness everywhere

## 更新内容

- 修复开启 Copilot 无障碍后，三星键盘等输入法每个键要点两次的问题：Copilot 平时用普通的服务名，只在操作微信时临时换成读屏服务名（先用 TalkMan，不够再用 TalkBack），交给你操作、离开微信或任务结束时立刻换回，你自己打字不再受影响
- 系统「无障碍」列表里会多出「Copilot · 微信」两项，由 Copilot 自动开关，不需要手动打开

## What's new

- Fixed keyboards such as Samsung Keyboard needing two taps per key while Copilot’s accessibility service is on: Copilot now runs under an ordinary service name and switches to a screen-reader name only while it operates WeChat (TalkMan first, TalkBack if needed), switching back as soon as it hands control to you, leaves WeChat or finishes, so your own typing is never affected
- Android’s Accessibility list shows two extra “Copilot · WeChat” entries; Copilot turns them on and off by itself, so you never need to

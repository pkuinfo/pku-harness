## 更新内容

- Copilot 的点按、滑动、滚动、滑块、输入和提交改由手机助手直接注入触摸和按键，不再通过无障碍操作（无障碍只用来读屏幕）。中文输入用粘贴，并在之后还原剪贴板
- 滑块会按读回的数值再校正一次，设到的值更准确

## What's new

- Copilot’s taps, swipes, scrolling, sliders, typing and submitting are now injected as touches and key presses by the phone helper instead of through accessibility actions (accessibility only reads the screen). Chinese text is pasted, and your clipboard is restored afterwards
- Sliders correct themselves once from the value read back, so they land on the requested value

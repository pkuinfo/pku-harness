## 更新内容

- Copilot 设置更简单：在通知里输入配对码即可，不再需要填写端口或分屏；连接后自动开启无障碍
- Copilot 的浮动窗口按应用比例显示，画面更大、更清楚
- 离开 App 后，Copilot 的确认请求会出现在浮动窗口里
- 计时器、时钟等不断变化的界面不再让 Copilot 的点按失败
- 更新提示改为底部面板，显示更新内容和下载进度
- 输入框不会再被键盘遮住；配对地址可直接粘贴「IP 地址:端口」

## What's new

- Simpler Copilot setup: type the pairing code into a notification, with no port and no split screen; accessibility turns on by itself once connected
- The Copilot floating window shows the app in its own shape, larger and easier to read
- After you leave the app, Copilot's approval requests appear in the floating window
- Live screens such as timers and clocks no longer make Copilot's taps fail
- The update prompt is now a bottom sheet with what's new and download progress
- Fields stay above the keyboard while you type; pairing addresses accept "IP address:port"

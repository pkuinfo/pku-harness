## 更新内容

- 上下文窗口默认使用模型上限：DeepSeek 显示为 100 万，用到约 90 万时才自动压缩
- Copilot 的「允许 AI 查看截图」默认开启，按截图坐标点按不再每次询问；淘宝、微信等不显示界面内容的应用也能直接操作
- Copilot 点按更可靠：搜索框提示轮换、倒计时等按钮文字原地变化时也能点；变化后若变成付款类操作会交给你确认
- 隐私政策更新：说明截图默认开启，可在 Copilot 设置中关闭

## What's new

- The context window defaults to the model’s maximum: 1M on DeepSeek, compacting only at about 900k
- Copilot’s “Let the AI see screenshots” is on by default, and taps at screenshot positions no longer ask each time, so apps that hide their contents (Taobao, WeChat) work directly
- Copilot taps more reliably: buttons whose text changes in place (a rotating search hint, a countdown) can be tapped; if the change turns it into a payment, it is handed to you
- Privacy policy update: screenshots are on by default and can be turned off in Copilot settings

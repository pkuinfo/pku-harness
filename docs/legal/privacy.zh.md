# 隐私政策

生效日期：2026 年 11 月 12 日

本政策说明 PKU harness 处理哪些数据、数据去向何处，以及你如何掌控这些数据。本政策适用于 PKU harness 应用、网站 harness.novadiffusion.com，以及由 pkuinfo 贡献者（以下称“我们”）运营的可选服务 PKU harness Cloud。PKU harness 与北京大学没有关联。

## 概要

- 你不需要在我们这里注册账号，我们没有用户数据库。
- 你的校园密码、手机令牌密钥和 AI 密钥都留在你的手机上，我们从不接收。
- 应用不含广告、统计分析或追踪 SDK。
- 应用直接连接校园服务和你选择的 AI 服务商。只有当你使用云功能时，我们的服务器才会经手数据，而且只能看到加密后的内容。

## 1. 保存在手机上的数据

应用把数据保存在你的手机上：
- **凭据**：学号、密码、IAAA 手机令牌密钥以及各校园服务的会话令牌。它们保存在 Android 加密存储中（SecureStore，由 Android Keystore 保护）。
- **AI 设置**：服务商地址、模型和 API 密钥（密钥保存在加密存储中）。
- **你的内容**：对话、你添加的附件、仪表盘组件、课表、待办、提醒、定时任务和插件数据。

这些数据留在你的手机上。加密存储中的内容不会进入 Android 备份。如果你开启了手机自带的云备份，Android 可能会把应用的其他数据一并备份，适用你的备份服务商的条款。**设置 → 清除所有数据** 会删除这些数据，卸载应用也会删除。**设置 → 导出数据** 只在你要求时生成文件，由你决定发送到哪里。

## 2. 校园服务

当你登录或使用校园功能时，应用从你的手机直接连接学校系统（例如 iaaa.pku.edu.cn、portal.pku.edu.cn、course.pku.edu.cn 和校园卡服务），并发送该服务需要的内容，登录时包括你的凭据。这与在浏览器中使用这些服务的方式相同。这部分数据适用学校自己的隐私规定，我们看不到。

## 3. 你的 AI 服务商

助手的工作方式是把对话发送给你配置的 AI 服务商（例如 DeepSeek 或其他兼容 OpenAI 接口的服务）。发送的内容可能包括：
- 你的消息和你添加的附件；
- 助手调用工具得到的结果，其中可能含有校园数据，例如课表、成绩、余额或树洞内容；
- 在 Copilot 模式下，你允许 Copilot 使用的应用的屏幕文字（界面上的文字和控件信息）。屏幕预览图只在手机上显示，不会发送给 AI。唯一的例外：当 Copilot 设置中的「允许 AI 查看截图」开启时（默认开启，你可以在该设置中关闭），对于淘宝、微信等不向 Copilot 显示内容的应用，助手可以把 Copilot 正在操作的应用的截图发送给你的 AI 服务商。截图只来自 Copilot 的独立屏幕，从不截取你自己正在使用的屏幕，也从不截取受保护的画面（例如密码、支付页面）；仅在当前所选模型能识别图片时发送，只用于当次回复，不保存在聊天记录中。你可以随时关闭此开关。

你的校园密码和手机令牌密钥永远不会发送给 AI。服务商依照其自己的条款和隐私政策处理这些数据，请选择你信任的服务商。我们不接收这些数据。

**语音输入（可选）。** 如果你设置了语音输入，你用麦克风按钮录下的语音会使用你自己的 API Key，从手机直接发送给你选择的语音识别服务（例如硅基流动或阿里云百炼），转成文字。该服务依照其自己的条款处理录音。录音转成文字后即从手机上删除，我们从不接收。只有在你录音时才会使用麦克风。

## 4. 插件

插件在应用内运行。每个插件都会声明它可以连接哪些主机、可以执行哪些操作，由你授予相应权限。在你授予的权限范围内，社区插件可能把数据发送到其作者的服务器，相关处理由插件作者负责。安装插件前，请阅读其说明和所需权限。

## 5. PKU harness Cloud（可选）

位于 harness.novadiffusion.com/cloud 的云服务只在你启用云功能（例如分享校园卡付款码）时使用。你可以在 **设置 → 云服务** 中关闭它或改用自己的服务器。
- 你的手机会生成一对密钥。服务器只能看到公钥，用它识别你的设备。
- 分享的内容在发送前就已在你的手机上加密。解密所需的密钥位于分享链接中 `#` 之后的部分，浏览器从不会把这部分发送给服务器。服务器无法读取付款码或其他分享内容。
- 服务器保存加密数据、数据大小和过期时间。分享通道最长 24 小时后过期（默认 15 分钟），过期后不久即被删除。存储的数据在过期或被你删除时删除。
- 服务器在内存中使用你的 IP 地址来限制滥用。其日志只记录请求类型、状态和耗时，不记录 IP 地址、内容、链接或令牌。

## 6. 更新和网站

- **新版本**：应用大约每天两次向 GitHub（api.github.com）查询最新版本，在你选择更新时从 GitHub 下载 APK。GitHub 能看到你的 IP 地址，并依照其隐私声明处理。
- **空中更新**：应用从 harness.novadiffusion.com 下载经过签名的更新文件。这些请求带有应用版本、平台，以及更新组件生成的随机安装 ID。服务器不保留这些请求的日志。
- **网站**：网站不使用追踪 Cookie 或统计分析。下载页面的版本信息由我们的服务器向 GitHub 查询，而不是由你的浏览器查询。

## 7. 应用申请的权限

- **通知、精确闹钟和电池优化**：用于按时发送提醒。
- **安装应用**：用于安装你选择的更新。
- **无障碍服务（仅 Copilot）**：在 Copilot 任务中读取和操作你允许的应用。
- **相机、照片和文件**：仅在你选择添加附件时使用。

你可以随时在 Android 设置中撤回任何权限。

## 8. 你的权利

你的数据保存在你的手机上，你可以随时在应用中查看、导出和删除。对于我们云服务上的数据，你可以在应用中删除，也可以联系我们协助处理。依照《中华人民共和国个人信息保护法》，你也可以向我们询问你的个人信息是如何被处理的。

## 9. 未成年人

PKU harness 面向北京大学的成员，不是为未满 14 周岁的儿童设计的。

## 10. 政策的变更

我们可能更新本政策。页首日期表示当前版本；发生重要变更时，应用会通知你。

## 11. 联系我们

关于隐私的问题或请求，请在 https://github.com/pkuinfo/pku-harness/issues 提交 issue；涉及敏感内容的，请按照 https://github.com/pkuinfo/pku-harness/security/policy 中的说明私下报告。
